# ITASEL Cloud – Desktop aplikacija

Ovaj repozitorij sadrži samo izvršne datoteke aplikacije ITASEL Cloud, objavljene kao **Releases**: instalacijski paketi za Windows (`.msi`, `.exe`), Linux (`.deb`, `.rpm`, `.AppImage`) i macOS (`.dmg`).

Aplikacija sama provjerava nova izdanja i nudi ažuriranje jednim dodirom, pa ručno preuzimanje obično nije potrebno.

- Web i prijava: <https://cloud.itasel.org>
- ITASEL: <https://itasel.org>
